# Commercial Break — Content Series Plan

**Concept:** 2026 ads for products from 1975–2005. Parody.
**Platform:** TikTok (repurposed account → "Commercial Break"), cross-posted to Reels/Shorts. LinkedIn gets the separate "how I made it" angle.
**Engine:** Mixtape (find a proven 2026 ad format → structure → new script) + /2minvid (render).
**Date:** November 6, 2026

---

## 1. The formula

Every episode = **one modern ad format** × **one old product** × **a year in the hook**.

```
[YEAR] + [2026 AD FORMAT] + [OLD PRODUCT] = joke
"1986" + "read-aloud 5-star review" + "cassette Walkman" 
```

The humor comes from the clash: today's ad tactics (urgency, "girl math", founder vulnerability, ASMR) applied to tech that was clunky by today's standards.

**Rules for every episode**
- Year on screen in the first frame (e.g., `1999`). Punchline lands by second 2.
- 15–25 seconds. One joke, one product.
- Generic products only (no real brands, logos, celebrities, or lookalikes).
- Original or royalty-free period-style music; recreate sounds (modem, tape click) rather than ripping recordings.
- Caption ends with: "Parody. Made with Mixtape."

## 5. Crossing decades — combination mechanics

Use these to keep the feed varied without inventing new concepts each time.

| Mechanic | How it works | Example |
|---|---|---|
| **Same format, new decade** | Run one format across 4 decades as a mini-series | "5-star reviews" for 1977 mood ring → 1986 Walkman → 1997 virtual pet → 2004 ringtone |
| **Same product family, across eras** | Show a category evolving through ads | Music: 8-track (1979) → cassette (1986) → Discman (1997) → burned CD (2001) → MP3 (2005) |
| **Decade vs. decade** | Comparison-table format between two eras | Walkman vs Discman, pager vs flip phone |
| **Era-swapped format** | A format that didn't exist yet, in an era where it makes no sense | 1975 "link in bio" for a pet rock (there is no bio) |
| **Duet the past** | A modern creator reacts to the parody ad as if it's real | "Wait, you had to rewind?" |

**Rotation rule:** never two posts in a row from the same decade or the same format. Cycle formats F1–F14 before repeating; cycle decades 2000s → 90s → 80s → 70s, weighted 40 / 30 / 20 / 10 (younger nostalgia has the biggest TikTok audience; 70s is a novelty spike).

## 8. Production pipeline per episode

1. Pick the format code → `mixtape spy` a brand known for that format, choose a long-running example.
2. `mixtape break` → `structure.json` (beat timing only).
3. Write the brief: "Year: 1999. Product: dial-up internet (generic). Format: POV. Tone: deadpan modern ad."
4. `mixtape hook` → pick the hook; `mixtape press` → `script.json`.
5. Add era style lock: color grade, film grain/VHS/early-digital look, period props, original period-style music.
6. Render with /2minvid; add year title card + "Parody. Made with Mixtape."
